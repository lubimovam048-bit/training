# Happy B'Day — приглашение в стиле The Sims

Одностраничный сайт-приглашение на 30-летие. Чистый HTML/CSS/JS + GSAP (CDN).

## Что поменять перед отправкой
Всё в начале `main.js`:
- `PARTY.start` — дата и время вечеринки (от неё считается обратный отсчёт и файл календаря);
- `PARTY.place` и `PARTY.mapUrl` — адрес и ссылка на карту;
- `MILESTONES` — истории для значков рубежей;
- `JOKES` — анекдоты собачки.

## Запуск локально
```
python3 -m http.server -d sims-bday 8000
```
